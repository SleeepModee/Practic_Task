Формат хранения данных
Данные хранятся в файле tasks.txt в текстовом формате. Каждая строка соответствует одной задаче, поля разделены символом |:
ID|Название|Статус(done/not done)|Приоритет|Дедлайн

id (int)
title (string)
done (bool)
priority (int)
deadline (string)

Список команд
add "название" -p [приоритет] -d [дата/none] - добавить новую задачу.

list - вывести все задачи.

done [id] - отметить задачу как выполненную.

undone [id] - отметить задачу как невыполненную.

delete [id] - удалить задачу.

clear - удалить все выполненные задачи.

help - показать справку по командам.

exit - завершить работу программы.
